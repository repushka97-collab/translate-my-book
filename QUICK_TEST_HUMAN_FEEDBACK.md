# 🧪 Быстрый тест системы Human Feedback

## 📋 Пошаговая инструкция

### Шаг 1: Найти переведенные PDF

```bash
python test_human_feedback.py
```

Скрипт найдет все переведенные PDF в `output/` и покажет инструкции.

---

### Шаг 2: Запустить веб-интерфейс

```bash
cd tools/human_feedback_interface
pip install flask flask-cors
python app.py
```

Вы увидите:
```
Starting Human Feedback Interface...
Open http://localhost:5000/feedback?book=your_book.pdf&page=1
 * Running on http://127.0.0.1:5000
```

---

### Шаг 3: Открыть в браузере

#### Вариант A: Через главную страницу
1. Откройте: `http://localhost:5000/`
2. Введите путь к переведенному PDF (например: `output/book_id/book_ru.pdf`)
3. Введите номер страницы (например: `1`)
4. Нажмите "Открыть страницу для оценки"

#### Вариант B: Прямая ссылка
```
http://localhost:5000/feedback?book=output/book_id/book_ru.pdf&page=1
```

Если есть оригинал:
```
http://localhost:5000/feedback?book=output/book_id/book_ru.pdf&page=1&original=test_pdfs/Book1.pdf
```

---

### Шаг 4: Оценить страницу

1. **Посмотрите на две страницы:**
   - Слева: оригинал
   - Справа: перевод

2. **Поставьте оценку:**
   - Переместите слайдер от 1 до 10
   - Оценка отображается справа

3. **Выделите проблемные области:**
   - Нажмите и перетащите мышью на изображении перевода
   - Появится красный прямоугольник
   - Введите описание проблемы (например: "text_overflow")
   - Выберите серьезность (low/medium/high)

4. **Добавьте комментарий:**
   - Опишите общие проблемы страницы

5. **Введите ваше имя:**
   - Для персональной модели (например: "test_user")

6. **Сохраните:**
   - Нажмите "💾 Сохранить оценку"
   - Вы увидите сообщение об успешном сохранении

---

### Шаг 5: Оценить еще несколько страниц

Повторите шаг 4 для 3-5 страниц (минимум для теста).

**Рекомендуется:** 10-20 страниц для хорошей модели.

---

### Шаг 6: Обучить модель

```bash
python tools/train_human_like_model.py --user test_user
```

Вы увидите:
```
[INFO] Загружено 5 примеров обратной связи для 'test_user'
[SUCCESS] Модель обучена и сохранена: models/quality/test_user_quality_model.pkl
```

---

### Шаг 7: Использовать в пайплайне

```bash
$env:USE_HUMAN_LIKE_EVALUATION="1"
$env:HUMAN_MODEL_USER="test_user"
python run_pipeline.py --source test_pdfs/Book1.pdf --mode fast
```

В логах вы увидите:
```
[HUMAN_METRICS] Using personalized model for test_user
[HUMAN_METRICS] Average human-like score: 7.5/10
[HUMAN_METRICS] Recommendation: 🟡 Хорошо - небольшие правки для 10% страниц
```

---

## 🎯 Минимальный тест (5 минут)

1. Запустите веб-интерфейс
2. Оцените 3 страницы
3. Обучите модель
4. Проверьте работу в пайплайне

---

## 📊 Проверка результатов

### Проверить сохраненную обратную связь:
```bash
cat human_feedback/test_user/*.json
```

### Проверить обученную модель:
```bash
ls models/quality/test_user_quality_model.pkl
```

### Проверить логи пайплайна:
Ищите строки с `[HUMAN_METRICS]` в выводе.

---

## 💡 Советы

- **Начните с 3-5 страниц** для быстрого теста
- **Оценивайте разные типы страниц:** с таблицами, формулами, изображениями
- **Будьте последовательны** в оценках для лучшей модели
- **Переобучайте модель** после сбора новых данных

---

## ❓ Проблемы?

### Веб-интерфейс не запускается:
```bash
pip install flask flask-cors
```

### Не находит PDF:
Проверьте пути в браузере - используйте относительные пути от корня проекта.

### Модель не обучается:
Убедитесь, что собрали минимум 3 примера обратной связи.
