# 🔧 Конкретные исправления для применения

## 🚨 Критические проблемы (исправить немедленно)

### 1. Ошибка в pdf_rebuilder_v2.py: неправильный порядок использования шрифтов

**Проблема:**
```python
# Строка 136-138: final_font определяется ДО pdf_font
final_font = pdf_font
if font_manager:
    final_font = font_manager.get_font_for_text(new_doc, base_font, translated_text)

# Строка 140-148: pdf_font определяется ПОСЛЕ final_font
if is_bold and is_italic:
    pdf_font = f"{base_font}-boldoblique"
```

**Решение:** Переместить определение `pdf_font` ПЕРЕД использованием `font_manager`.

---

### 2. Недостаточное сжатие Ghostscript

**Проблема:** Используется `/prepress`, что дает минимальное сжатие.

**Решение:** Использовать `/screen` или `/ebook` для лучшего сжатия, или добавить дополнительные параметры.

---

### 3. Font Manager не находит шрифты Windows

**Проблема:** Ищет только в ограниченных путях, не учитывает все варианты имен шрифтов Windows.

**Решение:** Расширить поиск, добавить больше вариантов имен (Arial.ttf, arial.ttf, ARIAL.TTF).

---

### 4. Много `except: pass` без логирования

**Проблема:** Ошибки теряются, сложно отлаживать.

### 5. Проблемы с кодировкой в Windows

**Проблема:** Unicode символы не отображаются в PowerShell.

**Решение:** Добавить `sys.stdout.reconfigure(encoding='utf-8')` во все скрипты.
