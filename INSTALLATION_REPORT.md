## 🔧 Рекомендации

### Для полной функциональности:

1. **Установить Microsoft C++ Build Tools** для `pdf-diff`:
   - Скачать: https://visualstudio.microsoft.com/visual-cpp-build-tools/
   - После установки: `pip install pdf-diff`

2. **Настроить WeasyPrint** (опционально):
   - Следовать инструкциям: https://doc.courtbouillon.org/weasyprint/stable/first_steps.html#installation
   - Или использовать альтернативу (Playwright для HTML→PDF)

3. **Mathpix** (опционально):
   - Требует API ключ и отдельную установку
   - Используется для распознавания формул
