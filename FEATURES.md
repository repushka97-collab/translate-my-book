# Новые возможности пайплайна

## 🎯 Основные улучшения

### 1. Обработка формул
- **Автоматическая детекция**: формулы определяются по математическим символам, LaTeX командам, индексам
- **Сохранение без перевода**: формулы остаются в оригинале
- **Красивое отображение**: формулы в HTML с центрированием и стилизацией

### 2. Продвинутое использование Layout API
- **Точное извлечение структуры**: blocks → lines → spans
- **Font signals**: размер, bold, italic из spans
- **Цвета текста**: извлечение и сохранение RGB цветов из Layout API
- **Точные bbox**: для всех элементов (блоки, изображения, таблицы)

### 3. Улучшенная детекция таблиц
- **Colspan/rowspan**: автоматическое определение объединенных ячеек
- **Детекция по линиям**: использование графических линий из PDF
- **Fallback на pdfplumber**: опциональная поддержка через `PDFPLUMBER_TABLES=1`

### 4. Контекстный перевод с LLM refine
- **Контекст из соседних блоков**: учитываются предыдущие и следующие блоки
- **Расширенный список важных типов**: heading1-3, abstract, introduction, conclusion
- **Сниженный порог**: улучшаются блоки от 100 символов
- **Использование**: режим `hybrid` в `configs/llm.yaml`

### 5. Улучшенная детекция списков
- **Bulleted**: •, -, *, ‣, ∙, ·, —, –, ○, ●, ▪, ▫
- **Numbered**: 1. 2. 3. или 1) 2) 3) или (1) (2) (3)
- **Lettered**: a) b) c) или A. B. C.
- **Roman**: i. ii. iii. или I. II. III.

### 6. PDF экспорт через Playwright
- **Сохранение layout**: точные размеры страниц, фон, цвета
- **Параметры**: `HTML_TO_PDF_PLAYWRIGHT=1`
- **Fallback**: автоматический fallback на старый PDFBuilder

### 7. Обработка фона и водяных знаков
- **Raster preview**: опциональная растеризация страниц
- **Интеграция в HTML**: через `HTML_BACKGROUND=1`
- **Настройка opacity**: через `HTML_BACKGROUND_OPACITY=0.1`

### 8. OCR fallback
- **MuPDF OCR**: встроенный OCR через `page.get_text("ocr")`
- **Tesseract fallback**: опциональная поддержка (если установлен)
- **Включение**: `OCR_FALLBACK=1`

### 9. Оптимизации для больших PDF
- **Обработка по частям**: raster preview для PDF > 100 страниц
- **Очистка памяти**: после каждого чанка
- **Управление памятью**: автоматическая очистка pixmaps после использования

### 10. Выборочное маскирование контента
- **Пропуск по паттернам**: regex паттерны для пропуска перевода
- **Пропуск по типам/ролям**: формулы, код, сноски и т.д.
- **Приоритетный перевод**: помечание важных блоков
- **Включение**: `SELECTIVE_MASK=1`

### 11. Инкрементальное обновление
- **Отслеживание изменений**: хеши страниц для определения изменений
- **Переперевод только измененных**: экономия времени и ресурсов
- **Кэширование переводов**: использование старых переводов для неизмененных блоков
- **Включение**: `INCREMENTAL_UPDATE=1`

## 🔧 Переменные окружения

### Основные
- `INGEST_RASTER_PREVIEW=1` - включить растеризацию страниц
- `HTML_TO_PDF_PLAYWRIGHT=1` - использовать Playwright для PDF экспорта
- `HTML_ABSOLUTE=0` - потоковый HTML (по умолчанию)
- `PDFPLUMBER_TABLES=1` - использовать pdfplumber для таблиц
- `OCR_FALLBACK=1` - включить OCR fallback

### HTML экспорт
- `HTML_BACKGROUND=1` - включить фон в HTML
- `HTML_BACKGROUND_OPACITY=0.1` - прозрачность фона (0.0-1.0)
- `RASTER_PREVIEW_DPI=200` - DPI для растеризации

### Оптимизации
- `INCREMENTAL_UPDATE=1` - включить инкрементальное обновление
- `SELECTIVE_MASK=1` - включить выборочное маскирование
- `MASK_SKIP_PATTERNS="pattern1,pattern2"` - паттерны для пропуска
- `MASK_SKIP_TYPES="formula,code"` - типы для пропуска
- `MASK_SKIP_ROLES="footnote,header"` - роли для пропуска

## 📊 Примеры использования

### Базовый запуск
```bash
python run_pipeline.py --source "book.pdf" --mode fast
```

### С фоном и Playwright PDF
```bash
$env:INGEST_RASTER_PREVIEW="1"
$env:HTML_TO_PDF_PLAYWRIGHT="1"
$env:HTML_BACKGROUND="1"
python run_pipeline.py --source "book.pdf" --mode fast
```

### С инкрементальным обновлением
```bash
$env:INCREMENTAL_UPDATE="1"
python run_pipeline.py --source "book.pdf" --mode fast
```

### С выборочным маскированием
```bash
$env:SELECTIVE_MASK="1"
$env:MASK_SKIP_PATTERNS="copyright,license"
$env:MASK_SKIP_TYPES="formula"
python run_pipeline.py --source "book.pdf" --mode fast
```

### Hybrid режим с LLM refine
```bash
python run_pipeline.py --source "book.pdf" --mode hybrid
```

## 🎨 Качество экспорта

### HTML
- Потоковый layout без наложений
- Сохранение цветов текста
- Формулы с красивым форматированием
- Таблицы с colspan/rowspan
- Изображения с подписями
- Опциональный фон/водяные знаки

### PDF (через Playwright)
- Точные размеры страниц
- Сохранение фона и цветов
- Идентичная верстка оригиналу

### DOCX
- Улучшенная типографика
- Таблицы с правильным форматированием
- Изображения с подписями
- Списки (bulleted/numbered)

## 🚀 Производительность

- **Batch processing**: автоматическая обработка по батчам
- **Memory optimization**: очистка памяти после каждого чанка
- **Incremental update**: переперевод только измененных блоков
- **Caching**: кэширование переводов для ускорения

## 📝 Примечания

- Все новые возможности опциональны и не влияют на базовую функциональность
- По умолчанию все оптимизации выключены для совместимости
- Для больших PDF рекомендуется включить `INCREMENTAL_UPDATE=1`
- Для научных книг с формулами рекомендуется `SELECTIVE_MASK=1` с `MASK_SKIP_TYPES="formula"`
