# 🧪 Пошаговый тест системы Human Feedback

## ✅ Найдено 6 переведенных PDF для тестирования!

---

## 📋 Шаг 1: Запустить веб-интерфейс

### Вариант A: Автоматический запуск (Windows)
```bash
START_HUMAN_FEEDBACK.bat
```

### Вариант B: Ручной запуск
```bash
cd tools/human_feedback_interface
pip install flask flask-cors
python app.py
```

**Ожидаемый вывод:**
```
Starting Human Feedback Interface...
Open http://localhost:5000/feedback?book=your_book.pdf&page=1
 * Running on http://127.0.0.1:5000
```

---

## 📋 Шаг 2: Открыть в браузере

### Вариант A: Через главную страницу
1. Откройте: **http://localhost:5000/**
2. Введите путь к PDF: `output/16c9f47aa3421533/book_ru.pdf`
3. Введите номер страницы: `1`
4. Нажмите "Открыть страницу для оценки"

### Вариант B: Прямая ссылка
Откройте в браузере:
```
http://localhost:5000/feedback?book=output/16c9f47aa3421533/book_ru.pdf&page=1
```

---

## 📋 Шаг 3: Оценить страницу

### Что вы увидите:
- **Слева:** Оригинальная страница (английский)
- **Справа:** Переведенная страница (русский)

### Как оценить:

1. **Поставьте оценку:**
   - Переместите слайдер от 1 до 10
   - Оценка отображается справа от слайдера

2. **Введите ваше имя:**
   - Например: `test_user`
   - Это для персональной модели

3. **Выделите проблемные области (опционально):**
   - Нажмите и перетащите мышью на изображении перевода
   - Появится красный прямоугольник
   - Введите описание (например: `text_overflow`, `image_shift`)
   - Выберите серьезность: `low`, `medium`, или `high`

4. **Добавьте комментарий:**
   - Опишите общие проблемы страницы
   - Например: "Таблица сдвинулась вправо"

5. **Сохраните:**
   - Нажмите кнопку "💾 Сохранить оценку"
   - Вы увидите сообщение: "✅ Оценка сохранена!"

---

## 📋 Шаг 4: Оценить еще страницы

Повторите шаг 3 для **минимум 3-5 страниц** (для теста).

**Рекомендуется:** 10-20 страниц для хорошей модели.

**Быстрый способ:**
- Измените номер страницы в URL: `&page=2`, `&page=3`, и т.д.
- Или используйте главную страницу для ввода нового номера

---

## 📋 Шаг 5: Обучить модель

После оценки 3+ страниц, обучите модель:

```bash
python tools/train_human_like_model.py --user test_user
```

**Ожидаемый вывод:**
```
[INFO] Загружено 5 примеров обратной связи для 'test_user'
[SUCCESS] Модель обучена и сохранена: models/quality/test_user_quality_model.pkl
         Теперь можно использовать в пайплайне:
         USE_HUMAN_LIKE_EVALUATION=1
         HUMAN_MODEL_USER=test_user
```

## ❓ Проблемы?

### Веб-интерфейс не запускается:
```bash
pip install flask flask-cors
```

### Не загружаются изображения:
- Проверьте, что путь к PDF правильный
- Используйте относительные пути от корня проекта
- Убедитесь, что PDF существует

### Модель не обучается:
- Убедитесь, что собрали минимум 3 примера
- Проверьте: `dir human_feedback\test_user\`
