# 🔧 Решение проблемы с pdf-diff

## Проблема

`pdf-diff` требует `diff-match-patch-python`, который нужно компилировать из исходников. Даже после установки C++ Build Tools компилятор может быть не найден.

## Решения

### Вариант 1: Перезапустить терминал (рекомендуется)

После установки C++ Build Tools нужно:
1. **Закрыть текущий терминал/PowerShell**
2. **Открыть новый терминал**
3. **Попробовать снова:**
   ```bash
   pip install pdf-diff
   ```

### Вариант 2: Использовать Developer Command Prompt

1. Открыть "Developer Command Prompt for VS" (из меню Пуск)
2. Перейти в директорию проекта
3. Выполнить:
   ```bash
   pip install pdf-diff
   ```

### Вариант 3: Использовать альтернативу (уже работает!)

**Не обязательно устанавливать pdf-diff!**

В проекте уже есть полноценная альтернатива:
- ✅ `core_engine/qa/pixel_perfect_diff.py` - работает без установки дополнительных библиотек

Эта альтернатива предоставляет:
- Сравнение PDF на пиксельном уровне
- Метрики схожести
- Обнаружение смещений
- Анализ переполнения текста

### Вариант 4: Использовать diff-match-patch (уже установлен)

Мы уже установили `diff-match-patch` как альтернативу. Можно использовать его напрямую:

```python
from diff_match_patch import diff_match_patch
dmp = diff_match_patch()
```

---

## ✅ Рекомендация

**Используйте альтернативу `core_engine/qa/pixel_perfect_diff.py`** - она уже работает и не требует компиляции!

Если все же нужен именно `pdf-diff`:
1. Перезапустите терминал
2. Попробуйте установить снова
3. Если не работает - используйте альтернативу
