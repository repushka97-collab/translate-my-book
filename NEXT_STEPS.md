## 🎯 Приоритетные задачи

### 1. Исправить слияние предложений на уровне блоков (КРИТИЧНО)
**Проблема**: QA видит 42 potential_break, потому что проверяет блоки ДО слияния  
**Решение**:
- Добавить слияние предложений в `normalize_blocks` (до перевода)
- Или переместить QA check после layout (проверять paragraph_stream вместо блоков)
- **Ожидаемый результат**: potential_break < 10

**Файлы для изменения**:
- `core_engine/normalize/text_cleaner.py` - добавить слияние
- `core_engine/orchestrator/pipeline.py` - переместить QA check

### 2. Pre-processing заголовков ДО перевода (ВАЖНО)
**Проблема**: Словарь применяется ПОСЛЕ перевода, когда уже поздно  
**Решение**:
- Применять словарь в `normalize_blocks` для заголовков
- Использовать исходный текст для поиска в словаре
- **Ожидаемый результат**: 95%+ правильных переводов заголовков

**Файлы для изменения**:
- `core_engine/normalize/text_cleaner.py` - добавить pre-processing заголовков
- `core_engine/translate/heading_translator.py` - использовать в normalize

### 3. Интегрировать метрики качества в QA (ВАЖНО)
**Решение**:
- Добавить BLEU/ROUGE scores в `qa_check_blocks`
- Визуализация качества по страницам
- **Ожидаемый результат**: Объективная оценка качества

**Файлы для изменения**:
- `core_engine/qa/integrity_check.py` - интегрировать translation_metrics
- `core_engine/qa/translation_metrics.py` - уже создан

### 4. Расширить словарь заголовков (СРЕДНИЙ ПРИОРИТЕТ)
**Решение**:
- Собрать частые заголовки из реальных PDF
- Добавить в `HEADING_DICTIONARY`
- **Ожидаемый результат**: Больше заголовков переводится правильно

**Файлы для изменения**:
- `core_engine/translate/heading_translator.py` - расширить словарь

### 5. Улучшить логику слияния предложений (СРЕДНИЙ ПРИОРИТЕТ)
**Решение**:
- Более агрессивное слияние
- ML-модель для классификации (опционально)
- **Ожидаемый результат**: Меньше разорванных предложений

**Файлы для изменения**:
- `core_engine/layout/sentence_merger.py` - улучшить логику
