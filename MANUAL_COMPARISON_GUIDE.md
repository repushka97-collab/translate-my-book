# 📊 Руководство по ручному сравнению PDF

## ✅ Результаты прогона

После полного прогона созданы переведенные PDF в `output/`:
- Все PDF успешно переведены

---

## 🔍 Варианты сравнения

### Вариант 1: Инструмент для сравнения

```bash
python tools/compare_pdfs_manual.py
```

**Что делает:**
1. Находит все переведенные PDF
2. Предлагает выбрать PDF для сравнения
3. Открывает оригинал и перевод рядом (Windows)
4. Или создает HTML страницу для сравнения в браузере

---

### Вариант 2: Веб-интерфейс для оценки

```bash
cd tools/human_feedback_interface
python app.py
```

Откройте в браузере:
```
http://localhost:5000/feedback?book=output/16c9f47aa3421533/book_ru.pdf&page=1
```

**Возможности:**
- Сравнение оригинал vs перевод
- Оценка от 1 до 10
- Выделение проблемных областей
- Комментарии

---

### Вариант 3: Ручное открытие PDF

1. Откройте оригинал в PDF просмотрщике
2. Откройте перевод в другом окне
3. Расположите окна рядом
4. Сравните страницу за страницей

**Пути к PDF:**
- Оригиналы: `For test/`, `ingest/`
- Переводы: `output/<book_id>/book_ru.pdf`

## 📋 Чек-лист для оценки

### ✅ Что проверять:

1. **Текст:**
   - [ ] Весь текст переведен
   - [ ] Нет пропущенных фрагментов
   - [ ] Качество перевода (точность, стиль)

2. **Верстка:**
   - [ ] Текст не выходит за границы
   - [ ] Таблицы сохранены
   - [ ] Изображения на месте
   - [ ] Формулы читаемы

3. **Структура:**
   - [ ] Заголовки на месте
   - [ ] Списки сохранены
   - [ ] Разрывы страниц корректны

4. **Визуальное:**
   - [ ] Шрифты читаемы
   - [ ] Цвета сохранены
   - [ ] Общий вид похож на оригинал

---

## 🎯 Найденные проблемы

### Из Quality Scorecard:

1. **Layout Preservation: 60-68%** 
   - Структурное сходство ниже порога
   - Требуется проверка иерархии элементов

2. **Page Count Mismatch**
   - Количество страниц не совпадает
   - Проверить разрывы страниц

3. **File Size Ratio: 1.03-1.66x**
   - Некоторые PDF увеличены более чем на 25%
   - Применить сжатие через Ghostscript

4. **Font Consistency: 0-14%**
   - Шрифты не сохраняются
   - Требуется улучшение
