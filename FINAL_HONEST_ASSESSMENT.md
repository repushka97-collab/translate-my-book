## 🎯 ПРИЧИНЫ ПРОБЛЕМ

### 1. HTML→PDF конвертация имеет ограничения
- **Проблема**: Playwright конвертирует HTML в PDF, но не сохраняет точные позиции
- **Причина**: HTML flow/absolute layout не идеально соответствует PDF координатам
- **Решение**: Нужен PDF_REBUILD_V2 с поддержкой Unicode шрифтов

### 2. PyMuPDF compression недостаточно эффективен
- **Проблема**: Сжатие через PyMuPDF дает только 2.39x вместо <1.5x
- **Причина**: PyMuPDF compression не такой эффективный как Ghostscript
- **Решение**: Установить Ghostscript или использовать более агрессивное сжатие

### 3. Алгоритм сравнения layout не учитывает особенности HTML→PDF
- **Проблема**: Layout Preservation 57% даже с absolute positioning
- **Причина**: Алгоритм сравнения слишком строгий для HTML→PDF конвертации
- **Решение**: Улучшить алгоритм сравнения или использовать PDF_REBUILD
