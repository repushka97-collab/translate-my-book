# 🧪 Как опробовать систему Human Feedback

## ✅ Найдено 6 переведенных PDF для тестирования!

---

## 🚀 Быстрый старт (3 команды)

### 1️⃣ Запустить веб-интерфейс

```bash
cd tools/human_feedback_interface
pip install flask flask-cors
python app.py
```

Вы увидите:
```
Starting Human Feedback Interface...
Open http://localhost:5000/feedback?book=your_book.pdf&page=1
 * Running on http://127.0.0.1:5000
```

---

### 2️⃣ Открыть в браузере

**Вариант A: Через главную страницу**
1. Откройте: **http://localhost:5000/**
2. Введите путь: `output/16c9f47aa3421533/book_ru.pdf`
3. Введите страницу: `1`
4. Нажмите "Открыть страницу для оценки"

**Вариант B: Прямая ссылка**
```
http://localhost:5000/feedback?book=output/16c9f47aa3421533/book_ru.pdf&page=1
```

---

### 3️⃣ Оценить страницы и обучить модель

1. **Оцените 3-5 страниц:**
   - Поставьте оценку от 1 до 10
   - Выделите проблемные области (опционально)
   - Добавьте комментарии
   - Введите имя: `test_user`
   - Сохраните

2. **Обучите модель:**
   ```bash
   python tools/train_human_like_model.py --user test_user
   ```

3. **Используйте в пайплайне:**
   ```bash
   $env:USE_HUMAN_LIKE_EVALUATION="1"
   $env:HUMAN_MODEL_USER="test_user"
   python run_pipeline.py --source "For test/Book1.pdf" --mode fast
   ```

## 📋 Детальная инструкция

### Что вы увидите в интерфейсе:

- **Слева:** Оригинальная страница (английский)
- **Справа:** Переведенная страница (русский)
- **Слайдер:** Оценка от 1 до 10
- **Поле имени:** Для персональной модели
- **Комментарий:** Текстовое описание проблем

### Как оценить:

1. **Посмотрите на две страницы** - сравните оригинал и перевод
2. **Поставьте оценку** - переместите слайдер (1-10)
3. **Выделите проблемы** (опционально):
   - Нажмите и перетащите мышью на изображении перевода
   - Введите описание: `text_overflow`, `image_shift`, и т.д.
   - Выберите серьезность: `low`, `medium`, `high`
4. **Добавьте комментарий** - опишите общие проблемы
5. **Введите имя** - например: `test_user`
6. **Сохраните** - нажмите "💾 Сохранить оценку"

## 💡 Советы

- **Начните с 3-5 страниц** для быстрого теста
- **Оценивайте разные типы:** текст, таблицы, формулы
- **Будьте последовательны** в оценках
- **Минимум 10 страниц** для хорошей модели

## ❓ Проблемы?

### Flask не установлен:
```bash
pip install flask flask-cors
```

### Не загружаются изображения:
- Проверьте путь к PDF (используйте относительные пути)
- Убедитесь, что PDF существует

### Модель не обучается:
- Убедитесь, что собрали минимум 3 примера
- Проверьте: `dir human_feedback\test_user\`
