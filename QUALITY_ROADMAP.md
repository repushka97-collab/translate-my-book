# План улучшения качества перевода и верстки

## 🎯 Критические проблемы (42 potential_break)

### Проблема 1: Разорванные предложения между блоками
**Текущее состояние**: 42 случая в QA отчете  
**Причина**: PDF разбивает предложения на несколько блоков  
**Решение**:
1. Улучшить логику слияния в `layout_reassemble_v2.py`
2. Использовать контекстный анализ (N-граммы)
3. Учитывать синтаксические маркеры (союзы, предлоги)
4. ML-модель для классификации: продолжение vs новое предложение

**Ожидаемый результат**: < 10 potential_break

---

## 🔤 Проблема 2: Плохой перевод заголовков

### 2.1 Заголовки в капсе переводятся неправильно
**Пример**: "INDEPENDENT LEARNING ACTIVITIES 33" → "СОГЛАСНЫЕ УЧЕНИЕ 33"  
**Причина**: NLLB плохо работает с капсом, особенно с числами  
**Решение**:
1. **Pre-processing заголовков**: нормализовать капс перед переводом
2. **Post-processing**: специальная обработка заголовков после перевода
3. **Словарь заголовков**: частые заголовки переводить через словарь
4. **Гибридный подход**: для заголовков использовать LLM refine (Ollama)

**Ожидаемый результат**: 95%+ правильных переводов заголовков

### 2.2 Обрывки заголовков
**Пример**: "в Физической терапии 5" (обрывок)  
**Причина**: Заголовок разбит на несколько блоков  
**Решение**:
1. Улучшить детекцию заголовков по font signals
2. Объединять соседние блоки с большим шрифтом
3. Контекстный анализ: если следующий блок - продолжение заголовка

## 📐 Проблема 3: Верстка DOCX

### 3.1 Неправильные отступы и интервалы
**Проблема**: Параграфы слишком близко/далеко друг от друга  
**Решение**:
1. Улучшить стили в `docx_exporter.py`
2. Правильные отступы для списков
3. Интервалы между заголовками и текстом
4. Отступы для цитат и блоков

### 3.2 Таблицы теряют форматирование
**Проблема**: Таблицы не сохраняют выравнивание, границы  
**Решение**:
1. Улучшить парсинг таблиц
2. Сохранение выравнивания колонок
3. Правильные границы и стили

### 3.3 Изображения неправильного размера
**Проблема**: Изображения слишком большие/маленькие  
**Решение**:
1. Автоматическое масштабирование по размеру страницы
2. Сохранение пропорций
3. Оптимальный размер для DOCX

## 🔍 Проблема 4: Детекция структуры

### 4.1 Заголовки неправильно классифицируются
**Проблема**: heading1 vs heading2 vs paragraph  
**Решение**:
1. Улучшить эвристики в `heading_detector.py`
2. Использовать font signals более агрессивно
3. Контекстный анализ: позиция на странице, соседние блоки

### 4.2 Главы не детектируются
**Проблема**: Part/Chapter/Section не всегда находятся  
**Решение**:
1. Расширить паттерны в `chapter_detector.py`
2. Использовать исходный текст (до перевода) для детекции
3. Улучшить нормализацию разорванных заголовков
