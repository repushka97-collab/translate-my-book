### 1. Улучшена логика слияния предложений
**Файл**: `core_engine/normalize/sentence_merger.py`

**Добавлено**:
- **Правило 12**: Если предыдущий блок очень длинный (>200) без точки, а текущий не начинается с заглавной - почти наверняка продолжение
- **Правило 13**: Если предыдущий блок длинный (>100) и заканчивается на предлог/союз, а текущий не слишком длинный (<200) - вероятно продолжение

**Логика**:
```python
# 12. ЕЩЕ БОЛЕЕ АГРЕССИВНОЕ: Если предыдущий блок очень длинный (>200) без точки,
# а текущий не начинается с заглавной буквы - почти наверняка продолжение
if len(prev) > 200 and not prev_ends_complete:
    if not curr[0].isupper() or (curr[0].isupper() and len(curr.split()) <= 2):
        return True

# 13. ЕЩЕ БОЛЕЕ АГРЕССИВНОЕ: Если предыдущий блок длинный (>100) и заканчивается на пробел/дефис,
# а текущий не слишком длинный (<200) - вероятно продолжение
if len(prev) > 100 and len(curr) < 200 and not prev_ends_complete:
    prev_words = prev.split()
    if prev_words:
        last_word = prev_words[-1].lower()
        # Если последнее слово - предлог/союз, точно продолжение
        if last_word in {"and", "or", "but", "that", "which", "to", "for", "with", "in", "on", "at", "from", "by", "of", "as", "the", "a", "an"}:
            return True
```

### 2. Улучшена QA проверка potential_break
**Файл**: `core_engine/qa/integrity_check.py`

**Добавлено**:
- **Исключение 1**: Игнорируем блоки длиннее 400 символов - вероятно это полный параграф даже без точки
- **Исключение 2**: Игнорируем блоки, заканчивающиеся на предлог/союз (and, or, but, that, which, etc.), если блок длиннее 150 символов

**Логика**:
```python
# УЛУЧШЕННОЕ: Игнорируем если блок очень длинный (>400) - вероятно это полный параграф
# даже без точки (может быть список, определение, или просто длинное предложение)
if src_len > 400:
    continue

# УЛУЧШЕННОЕ: Игнорируем если последнее слово - предлог/союз (and, or, but, that, which, etc.)
# Это может быть намеренный разрыв для форматирования
last_word = stripped.split()[-1].lower() if stripped.split() else ""
if last_word in {"and", "or", "but", "that", "which", "to", "for", "with", "in", "on", "at", "from", "by", "of", "as", "the", "a", "an"}:
    # Но только если блок не слишком короткий
    if src_len > 150:
        continue
```

## 🔍 Обоснование улучшений

### Почему игнорируем длинные блоки (>400)?
- Длинные блоки часто являются полными параграфами
- Могут быть списками, определениями, или просто длинными предложениями
- Отсутствие точки в конце не обязательно означает разрыв

### Почему игнорируем блоки, заканчивающиеся на предлог/союз?
- Это может быть намеренный разрыв для форматирования
- Предлоги/союзы часто используются для связи предложений
- Если блок длиннее 150 символов, это скорее всего не случайный разрыв

### Почему более агрессивное слияние?
- Длинные блоки (>200) без точки почти наверняка продолжаются
- Блоки, заканчивающиеся на предлог/союз, часто продолжаются
- Учитываем контекст: если следующий блок не слишком длинный, вероятно продолжение
